# 抽奖系统说明

每个抽奖项目属于一个活动，可以设置多个必需成就和多个奖品。参与者必须在同一浏览器中集齐全部必需成就，才会进入候选池。

奖品概率以万分比保存：`10000` 等于 100%，`1250` 等于 12.5%。全部奖品合计不得超过 100%，未分配部分为“本次未中奖”。奖品库存耗尽后，它原来的概率区间也按未中奖处理，不会提高其他奖品概率。

工作人员从管理台执行抽取。服务器使用事务锁避免并发超发，并保证同一匿名设备在同一个抽奖项目中最多中奖一次。中奖结果绑定领取成就时生成的设备 Cookie；学生可在原手机、原浏览器的“我的奖品”页面向工作人员出示结果。清除浏览器数据或换浏览器后无法恢复本机展示，因此重要奖项还应由工作人员记录中奖编号。
